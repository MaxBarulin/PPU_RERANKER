Загрузить реестр

Лист и колонки находятся сами: нужны «Наименование», «До улучшения», «После улучшения», «Предложения». Векторы уже посчитанных записей берутся из кэша — считаются только новые и изменённые. Пока идёт сборка, проверка ППУ работает по старой базе.

Калибровка порогов

Пороги «повтор / похоже / уникально» по умолчанию подобраны на выдуманных ППУ. Чтобы они подходили к вашему реестру, люди размечают пары похожих ППУ, а пороги подбираются по разметке.

загрузка…
1

Выбрать пары

Пары — ППУ из реестра и их ближайшие соседи, поровну по степени похожести. 240 пар размечаются примерно за 40–60 минут. Можно добавлять ещё — сделанная разметка сохраняется.

2

Разметить

Размечать пары →

Можно прерываться и размечать вдвоём: метки сохраняются сразу.

3

Подобрать и применить пороги

Нужно хотя бы по 5 пар «повтор / то же, другое подразделение» и остальных. Применённые пороги начинают работать со следующей проверки, перезапуск не нужен.
