Обновление базы и калибровка доступны только по паролю. Его знает ответственный за сервис.

Калибровка порогов

Пороги «повтор / похоже / уникально» по умолчанию подобраны на выдуманных ППУ. Чтобы они подходили к вашему реестру, люди размечают пары похожих ППУ, а пороги подбираются по разметке.

загрузка…
1

Выбрать пары

Пары — ППУ из реестра и их ближайшие соседи, поровну по степени похожести. 240 пар вручную размечаются примерно за 40–60 минут. Можно добавлять ещё — сделанная разметка сохраняется.

2

Разметить

Размечать вручную → проверить метки LLM →

Вручную: можно прерываться и размечать вдвоём, метки сохраняются сразу. С помощью LLM: судья размечает все ещё не размеченные пары по тем же правилам. Это идёт в фоне, страницу можно закрыть. Ответы LLM можно проверить и поправить: «проверить метки LLM».

3

Подобрать и применить пороги

Нужно хотя бы по 5 пар «повтор / то же, другое подразделение» и остальных. Применённые пороги начинают работать со следующей проверки, перезапуск не нужен.
