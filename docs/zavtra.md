# План на завтра: запуск на сервере srv-ai

Цель: запустить веб проверки ППУ и загрузить реестр **через браузер**.
Модели уже работают на сервере, их не трогаем.

| Что | Где |
|---|---|
| чужой веб-интерфейс к LLM | порт **8000** — не трогаем |
| сервер эмбеддингов bge-m3 | `127.0.0.1:8001` |
| LLM (судья) | `127.0.0.1:8004` |
| **наш веб** | порт **8010** |

Все команды выполняются на сервере (`barulin.ma@srv-ai`).

---

## Шаг 1. Убрать вчерашнее и подтянуть код

```bash
cd ~/PPU_RERANKER
pkill -f ppu.web          # остатки вчерашних запусков (если нет — ничего страшного)
rm -f nohup.out
git checkout master
git pull
```

Проверка: должна появиться папка `scripts/linux`:

```bash
ls scripts/linux          # start.sh  stop.sh  update.sh
```

## Шаг 2. Проверить, что модели отвечают

```bash
curl http://127.0.0.1:8001/v1/models
curl http://127.0.0.1:8004/v1/models
```

- Оба запроса должны вернуть JSON со списком моделей.
- На **8001** должна быть **bge-m3**: под неё настроены пороги вердикта.
- Запомните `"id"` модели на **8004**, он понадобится в `.env`.

## Шаг 3. Настроить `.env`

```bash
nano .env
```

Нужны такие строки (остальное можно не трогать):

```
EMB_BASE_URL=http://127.0.0.1:8001/v1
EMB_MODEL=bge-m3
LLM_BASE_URL=http://127.0.0.1:8004/v1
LLM_MODEL=<id модели с 8004 из шага 2>
PPU_PORT=8010
PPU_ADMIN_TOKEN=<пароль на обновление базы — придумать>
```

Сохранить: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

> Если `.env` ещё нет: `cp .env.example .env` (имя начинается с точки).

## Шаг 4. Запустить веб

```bash
scripts/linux/start.sh
```

Должно получиться примерно так:

```
Модели из .env:
  эмбеддинги: OK  (http://127.0.0.1:8001/v1)
  LLM-судья : OK  (http://127.0.0.1:8004/v1)

Работает (PID 12345):
  проверка ППУ:     http://10.x.x.x:8010
  обновление базы:  http://10.x.x.x:8010/admin
```

- **Первый запуск** сам поставит зависимости, это займёт минуту.
- **Если пишет `НЕ ОТВЕЧАЕТ`**, вернитесь к шагу 2.
- **Если пишет `Порт 8010 занят`**, поставьте в `.env` `PPU_PORT=8011` (или другой свободный) и запустите снова.

Терминал после этого можно закрыть: веб продолжит работать.

## Шаг 5. Загрузить реестр

На своём компьютере, в браузере:

1. Открыть `http://<IP сервера>:8010/admin` (IP скрипт напечатал в шаге 4).
2. Выбрать файл реестра `PPU.xlsx`. Если файл в старом формате `.xls`,
   пересохраните его в Excel как «Книга Excel (.xlsx)».
3. Ввести пароль из `PPU_ADMIN_TOKEN`.
4. Нажать **«Загрузить и пересобрать»**.

Дальше на странице виден ход сборки: «Векторы: названия (часть 1 из 4) — 3 200 из 11 000».
Первая сборка самая долгая: считаются все записи. Страницу можно закрыть, сборка продолжится.

Когда появится зелёное **«Готово: в базе N ППУ»**:

- раскройте **«Отчёт о данных»** и посмотрите, сколько записей без
  описания и какие сокращения не раскрыты;
- перезапускать ничего не нужно, проверка уже работает по новой базе.

**Если оборвалось** (ошибка, упал сервер эмбеддингов), нажмите **«Пересобрать
из последнего файла»**: посчитанное возьмётся из кэша.

**Если страница не открывается с компьютера**, скорее всего, порт 8010 закрыт сетевым экраном (8000 ведь открыт). Варианты:
- попросить админа открыть порт 8010 на srv-ai;
- временно через SSH-туннель: в `cmd` на своём компьютере выполнить
  `ssh -L 8010:127.0.0.1:8010 barulin.ma@srv-ai`, окно не закрывать,
  открыть http://127.0.0.1:8010/admin.

## Шаг 6. Проверить работу

1. Открыть `http://<IP сервера>:8010`.
2. В шапке должно быть: «в реестре N ППУ · индекс от …».
3. Вставить ППУ, которое точно есть в реестре, и нажать «Проверить»: должно
   найтись само себя с вердиктом «Такое ППУ уже было».
4. Нажать «Уточнить у LLM»: проверка, что судья на 8004 отвечает.

## Шаг 7 (когда будет время). Калибровка порогов

Пороги «повтор / похоже / уникально» по умолчанию подобраны на выдуманных ППУ.
Подстроить их под реальный реестр можно на той же странице `/admin`, раздел
**«Калибровка порогов»**:

1. **«Выбрать пары»**: 240 пар похожих ППУ из реестра, это секунды.
2. **«Размечать пары →»**: две ППУ рядом, клавиши `1`–`5` (повтор … не связаны),
   `0` — непонятно, `Backspace` — назад. 240 пар займут примерно 40–60 минут, можно прерываться
   и размечать вдвоём.
3. **«Показать, что изменится»**: отчёт, как поменяются вердикты.
   **«Применить пороги»** включает новые пороги сразу, без перезапуска.
   Не понравилось — **«вернуть пороги по умолчанию»**.

Мало разметки — нажмите «Добавить пары»: уже размеченное сохранится.

Не хочется размечать руками — на шаге 2 нажмите **«Разметить с помощью LLM»**:
судья с 8004 разметит пары сам (в фоне, страницу можно закрыть). Потом стоит
пролистать «проверить метки LLM →» и поправить, с чем не согласны, — и подобрать пороги.

## Шпаргалка

| Что | Команда (из `~/PPU_RERANKER`) |
|---|---|
| запустить | `scripts/linux/start.sh` |
| остановить | `scripts/linux/stop.sh` |
| перезапустить | `scripts/linux/stop.sh && scripts/linux/start.sh` |
| лог в реальном времени | `tail -f logs/web.log` (выйти — `Ctrl+C`, веб продолжит работать) |
| последние ошибки | `tail -50 logs/web.log` |
| обновить код и перезапустить | `scripts/linux/update.sh` |
| обновить базу | браузер → `/admin` → загрузить новый `.xlsx` |

Автоподъём после падения веба или перезагрузки сервера (по желанию): `crontab -e` и добавить строку

```
*/5 * * * * cd ~/PPU_RERANKER && scripts/linux/start.sh >> logs/start.log 2>&1
```

Раз в 5 минут скрипт проверяет, жив ли веб, и запускает его, если нет. Как
проверить, что это работает, описано в [linux-server.md](linux-server.md#автоподъём-после-падения-и-перезагрузки).

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `НЕ ОТВЕЧАЕТ` у эмбеддингов | `curl http://127.0.0.1:8001/v1/models`; если не отвечает, сервер эмбеддингов не запущен |
| на /admin ошибка `APIConnectionError` | то же: сборке нужен сервер на 8001 |
| `Не найден лист с колонками` | в Excel нет колонок «Наименование», «До улучшения», «После улучшения», «Предложения» |
| `Неверный пароль администратора` | пароль не совпадает с `PPU_ADMIN_TOKEN` в `.env` (после правки `.env` перезапустить веб) |
| судья LLM отвечает ошибкой про `reasoning` | добавить в `.env` `LLM_EXTRA_BODY={"chat_template_kwargs": {"enable_thinking": false}}` и перезапустить |
| «Веб не запустился» | скрипт сам покажет последние строки лога; прислать их Claude |

Подробнее: [linux-server.md](linux-server.md).

## Следующий шаг: подключение к базе данных

Чтобы вместо Excel брать реестр напрямую из БД, нужно узнать:

1. **Тип СУБД:** PostgreSQL, MS SQL, Oracle, MySQL…
2. **Как подключаться с srv-ai:** адрес, порт, имя базы и учётка только на чтение.
3. **Откуда брать данные:** таблица или представление (view), из которых делалась Excel-ка.
4. **Как называются колонки** для: рег. №, наименование, до улучшения, после
   улучшения, предложения, статус, ЭЭ, даты.

С этим можно будет сделать кнопку «Обновить из базы» на той же странице `/admin`:
сборка индекса уже устроена так, что источник меняется одной функцией.
